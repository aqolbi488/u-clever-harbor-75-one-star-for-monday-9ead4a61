## Entry

> One star. Monday kept us waiting an hour, served cold coffee, then billed us for the whole week.

## How it works

`main.ts` (Node 22) writes that single deterministic line to `/output/entry.txt`, after checking it against the gate: 1–180 characters, at most 25 words, one line, plain text.

Run it with:

```sh
node main.ts
```
